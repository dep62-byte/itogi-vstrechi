Полный локальный пакет «Итоги встречи»: установка в Codex/Claude Code, 7 карточек кейсов (3 с оригиналами), актуальный снимок правил BB, редактируемые макеты, Google upload/export/update, проверки структуры и версий.

Скачайте ZIP, распакуйте и откройте папку в Codex. Готовая команда для установки — в README. Google вход выполняется пользователем через браузер; пароль и токены в пакет не входят.

На выпуске проверены установка в пустую папку, сборка, Google import/export, сохранение смоделированной ручной правки, обновление того же ID и отказ при устаревшей версии. На компьютерах продавцов проверки ещё не проводились. Один ответственный на встречу; во время обновления не редактировать Google Slides параллельно.
